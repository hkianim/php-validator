# PHP Validator

کتابخانه‌ای سبک و قابل استفاده مجدد برای اعتبارسنجی داده‌ها در پروژه‌های PHP، مبتنی بر Laravel Validation، همراه با پیام‌های خطای فارسی و قواعد اعتبارسنجی عمومی.

## ویژگی‌ها

- استفاده از موتور اعتبارسنجی Laravel.
- پیام‌های خطای فارسی.
- پشتیبانی از قواعد استاندارد Laravel Validation.
- دارای قانون عمومی اعتبارسنجی شماره همراه ایران (`mobile`).
- امکان تعریف و ثبت قواعد اختصاصی در هر نمونه.
- امکان تعیین نام نمایشی فیلدها برای پیام‌های خطا.
- امکان تعریف پیام خطای سفارشی برای هر قانون و فیلد.
- سازگار با PHP 7.4 و نسخه‌های بالاتر.

## پیش‌نیازها

- PHP 7.4 یا بالاتر
- Composer

## نصب

```bash
composer require hkianim/php-validator
```

## استفاده

ابتدا کلاس `Validation` را فراخوانی و یک نمونه از آن ایجاد کنید:

```php
use Hkianim\PhpValidator\Validation;

$validation = new Validation();
```

سپس داده‌ها و قوانین اعتبارسنجی را به متد `validate` ارسال کنید:

```php
$result = $validation->validate(
    [
        'mobile' => '09123456789',
    ],
    [
        'mobile' => ['required', 'mobile'],
    ]
);
```

### پارامترهای متد validate

```php
validate(
    array $data,
    array $rules,
    array $attributes = [],
    array $messages = []
): array
```

| پارامتر | توضیحات |
|---|---|
| `data` | داده‌هایی که باید اعتبارسنجی شوند |
| `rules` | قوانین اعتبارسنجی هر فیلد |
| `attributes` | نام نمایشی فیلدها در پیام‌های خطا |
| `messages` | پیام‌های خطای سفارشی |

## ساختار خروجی

متد `validate` همیشه یک آرایه با ساختار یکسان برمی‌گرداند.

### اعتبارسنجی موفق

```php
[
    'valid' => true,
    'data' => [
        'mobile' => '09123456789',
    ],
    'errors' => [],
]
```

در صورت موفقیت، داده‌های اعتبارسنجی‌شده در کلید `data` قرار می‌گیرند.

### اعتبارسنجی ناموفق

```php
[
    'valid' => false,
    'data' => [],
    'errors' => [
        'mobile' => [
            'شماره همراه واردشده معتبر نیست.',
        ],
    ],
]
```

خطاهای هر فیلد در کلید `errors` قرار می‌گیرند.

## قواعد عمومی

تمام قوانین استاندارد Laravel Validation که توسط نسخه وابستگی این کتابخانه پشتیبانی می‌شوند، قابل استفاده هستند.

چند نمونه از قوانین پرکاربرد:

| قانون | توضیحات |
|---|---|
| `required` | الزامی بودن مقدار |
| `string` | رشته بودن مقدار |
| `integer` | عدد صحیح بودن |
| `numeric` | عددی بودن |
| `boolean` | درست یا نادرست بودن |
| `array` | آرایه بودن |
| `email` | معتبر بودن ایمیل |
| `min` | حداقل مقدار یا طول |
| `max` | حداکثر مقدار یا طول |
| `between` | قرار گرفتن بین دو مقدار |
| `in` | محدود بودن به مقادیر مشخص |
| `regex` | تطبیق با الگوی مشخص |

### قانون mobile

این کتابخانه یک قانون عمومی با نام `mobile` دارد که شماره همراه ایران را با الگوی زیر بررسی می‌کند:

```regex
^09[0-9]{9}$
```

مثال:

```php
$result = $validation->validate(
    [
        'mobile' => '09123456789',
    ],
    [
        'mobile' => ['required', 'mobile'],
    ]
);
```

## تعیین نام نمایشی فیلدها

برای نمایش نام فارسی فیلدها در پیام‌های خطا، از پارامتر سوم استفاده کنید:

```php
$result = $validation->validate(
    [
        'mobile' => '',
    ],
    [
        'mobile' => ['required', 'mobile'],
    ],
    [
        'mobile' => 'شماره همراه',
    ]
);
```

پیام خطای حاصل:

```text
وارد کردن فیلد شماره همراه الزامی است.
```

## پیام‌های خطای سفارشی

می‌توان برای یک قانون مشخص روی یک فیلد، پیام اختصاصی تعریف کرد:

```php
$result = $validation->validate(
    [
        'mobile' => '12345678901',
    ],
    [
        'mobile' => ['required', 'mobile'],
    ],
    [
        'mobile' => 'شماره همراه',
    ],
    [
        'mobile.mobile' => 'شماره تماس واردشده صحیح نیست.',
    ]
);
```

در این مثال، پیام سفارشی برای قانون `mobile` روی فیلد `mobile` نمایش داده می‌شود.

## تعریف قواعد اختصاصی

اگر پروژه‌ای به قانون اعتبارسنجی اختصاصی نیاز داشته باشد، می‌تواند آن را به نمونه مورد استفاده خودش اضافه کند.

برای این کار از متد `addRule` استفاده می‌شود:

```php
addRule(
    string $name,
    callable $callback,
    string $message
): void
```

### نمونه تعریف قانون اختصاصی

```php
$validation = new Validation();

$validation->addRule(
    'bank_account_type',
    function ($attribute, $value, $parameters, $validator) {
        return in_array(
            $value,
            ['htBank', 'htCash', 'htOthers'],
            true
        );
    },
    'نوع حساب انتخاب‌شده معتبر نیست.'
);
```

حالا می‌توان از قانون جدید در اعتبارسنجی استفاده کرد:

```php
$result = $validation->validate(
    [
        'hsbType' => 'htBank',
    ],
    [
        'hsbType' => ['required', 'bank_account_type'],
    ]
);
```

### آرگومان‌های callback

تابع callback قانون اختصاصی چهار آرگومان دریافت می‌کند:

| آرگومان | توضیحات |
|---|---|
| `$attribute` | نام فیلدی که در حال اعتبارسنجی است |
| `$value` | مقدار فیلد |
| `$parameters` | پارامترهای ارسال‌شده به قانون |
| `$validator` | نمونه Validator لاراول |

قواعد اختصاصی هر پروژه باید در همان پروژه تعریف شوند؛ این کتابخانه فقط زیرساخت ثبت و اجرای آن‌ها را فراهم می‌کند.

## استقلال قواعد اختصاصی

قواعد اختصاصی به همان نمونه‌ای محدود هستند که با `addRule` روی آن ثبت شده‌اند.

بنابراین ثبت یک قانون در یک نمونه، باعث اضافه شدن آن به نمونه‌های دیگر نمی‌شود.

```php
$validationA = new Validation();
$validationB = new Validation();

$validationA->addRule(
    'custom_rule',
    fn ($attribute, $value) => true,
    'مقدار معتبر نیست.'
);
```

در این مثال، قانون `custom_rule` فقط در `$validationA` در دسترس است.

# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-11-11

### Added

- Initial release of PHP Validator.
- Persian localization for common validation messages.
- Built-in `mobile` validation rule for Iranian mobile numbers.
- `Validation` class for validating input data.
- Support for custom validation rules through `addRule`.
- Support for custom field names and validation messages.
- Isolated custom rules per `Validation` instance.
- Validation result with a consistent structure containing `valid`, `data`, and `errors`.
- Initial documentation and validation tests.
